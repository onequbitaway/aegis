not make this Secret. The pod does not start until the Secret has these keys:

  {{ .Values.storage.postgres.secretKey }}: the database URL
{{- end }}
{{- if and (eq .Values.bus.kind "nats") (has .Values.bus.nats.auth.method (list "token" "user_password")) }}

{{- end }}
{{- if .Values.api.enabled }}
{{- range .Values.api.principals }}
{{- if .tokenEnv }}
  {{ .secretKey }}: the API token of {{ .id }} (32 characters or more)
{{- end }}
{{- end }}
{{- end }}
{{- end }}
{{- if .Values.api.enabled }}

The operator API has no TLS. To open the web console from your computer:

  kubectl --namespace {{ .Release.Namespace }} port-forward service/{{ include "aegis.fullname" . }} 8080:{{ .Values.service.port }}

Then open http://127.0.0.1:8080/ and enter an API token.
{{- end }}
