# Security policy

## Supported versions

AEGIS has no release at this time. Security fixes go to the `main` branch only.

## Report a vulnerability

Do not open a public issue for a vulnerability.

1. Open a private report at <https://github.com/onequbitaway/aegis/security/advisories/new>.
2. If you cannot use GitHub, send an email to <jadelman31@gatech.edu>.

Include this data in your report:

- A description of the vulnerability and its effect.
- The commit or version that you tested.
- The steps to reproduce the vulnerability.
- A possible correction, if you know one.

## After you send a report

- The maintainer reads each report and sends you a reply.
- The maintainer tells you when a correction is available.
- Keep the report private until the maintainer publishes the correction.

## Scope

This policy applies to the code and the default configuration in this repository. Report a
vulnerability in a dependency to the project that owns the dependency.
